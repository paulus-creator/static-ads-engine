# Referenz-Ads (Swipes)

Lokale Kopien der Design-Referenzen, ein Unterordner je Thema oder Produkt, je Datei
`<brand-slug>__<ad-id>.<ext>` plus eine `INDEX.md` mit Quelle, Beleg und Datum. KONZEPT
legt hier ab, was es aus Trendtrack holt; der Art Director legt seine Auswahl in
`art-director/` ab.

Dieser Ordner ist per `.gitignore` vom Repo ausgeschlossen. Fremde Ads werden nicht
weitergegeben, sie dienen nur als lokale Layout-Referenz.
