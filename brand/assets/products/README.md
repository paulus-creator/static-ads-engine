# Produktfotos

Ein Unterordner je Produkt-Kürzel (siehe `brand/PRODUKTE.md`), darin echte Fotos:
Freisteller auf Weiss, Packshot mit Schachtel, Flakon von vorn, bei Bedarf Detail des
Etiketts. Dateinamen in `PRODUKTE.md` eintragen.

Nie hier ablegen: generierte Bilder, Renders aus früheren Runs, Mockups. Regel 3 der Engine.
Dieser Ordner ist per `.gitignore` vom Repo ausgeschlossen.
