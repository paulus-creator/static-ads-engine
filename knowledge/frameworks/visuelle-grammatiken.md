# Visuelle Grammatiken — das Format-Menü für Vielfalt im Run

Bindend für KONZEPT (Referenz-Wahl) und JURY (Kontaktbogen).

## Der Befund, der dazu führte

Viele Statics fallen in dieselbe visuelle Sprache zurück: clean, beige, Editorial,
Serifenschrift. Sieht hochwertig aus, aber verschiedene Konzepte wirken im Feed wie
dieselbe Creative Family. Sie testen visuell dasselbe, obwohl die Angles verschieden
sind. Ein Konzept ist erst dann ein eigener Test, wenn es auf Thumbnail-Grösse erkennbar
anders aussieht.

## Die zwei Regeln

1. **Maximal ein Konzept je Run im Beige-/Editorial-Register.** Der Look ist nicht
   verboten, er ist ein Register von vielen, nicht der Default.
2. **Keine zwei Konzepte eines Runs nutzen dieselbe Grammatik.** Jedes Konzept muss auf
   dem Kontaktbogen (270 px) erkennbar ein anderes Bild sein.

## Das Menü

| Grammatik | Hinweise |
|---|---|
| Phone-Screenshot (Chat, Notizen, Suchleiste) | Inhalte = eigene Copy, nie erfundene Zitate als echt |
| Chat-Verlauf (Messenger-Optik) | wie oben; Marken-UI nachbilden nur mit Flag an den Owner |
| Forum-/Community-Post | Review-Inhalte nur echt |
| Notes-App-Liste | «5 Dinge, die ich mit 45 gern früher gewusst hätte» |
| Handschriftliche Notiz / Post-it | Marker-Typo, Kühlschrank oder Spiegel als Träger |
| Badezimmerregal-Foto | Alltags-Kontext, Produkt in Benutzung |
| Messy Real-Life-Snapshot | mit Text-Overlay |
| Vergleichs-Chart / Tabelle | bewusst gestaltet, nicht Dokument-Unfall (unten) |
| Kassenbon / Rechnung | als inszeniertes Format, nicht als Collage |
| Checkliste (✓/✗) | dito |
| Annotiertes Foto (Kreis, Pfeil, Unterstreichung) | stark für «genau hier»-Aussagen |
| Zeitungs-/Editorial-Clipping | keine echten Medienmarken, nur belegte Fakten |
| Produkt-Demonstration | Hände, Anwendung, Vorher/Nachher-Objekt (nicht Haut) |
| Diagramm / Mechanismus-Schaubild | Grafik-Disruption |
| Quote-Card | Zitat = eigene Copy oder echter Review |
| Ugly Ad / Direct-Response-Layout | bewusst laut, Anti-Marketing |
| Meme-Layout | Format-Codes der Plattform respektieren |
| Split-Karte (Them/Us, Vorher/Nachher) | Farbflächen-Kontrast |
| Zeitleiste / Schritte | «Nach 1/7/30 Nächten» |
| Review-Grid | drei Karten mit echten Reviews |
| Poster / Text-only | Typo trägt alles |

Das Menü ist ein Test-Menü, kein Ranking. Neue Grammatiken aus Referenzen ergänzen,
abgenutzte vermerken.

## Anzeige oder Unfall?

Ein Dokument-Format (Kassenbon, Tabelle, Checkliste) ist erlaubt, wenn es als **ein**
kohärentes Bild generiert ist: mit Licht, Textur, Inszenierung, oder als bewusst
gestaltetes Layout mit Typo-Hierarchie. Verboten bleibt dieselbe Information als Collage
aus freigestellten Einzelteilen ohne Licht und Schatten. Faustregel: **Generiert und
inszeniert = Grammatik. Montiert und gestückelt = Unfall.**

## Marken-UI

Messenger-, Forum- oder Notes-Optik darf die echte UI nachbilden, wenn der Owner das in
`brand/BRAND.md` erlaubt. Jedes solche Konzept trägt einen Hinweis «Marken-UI» im
Konzept-Eintrag; der Mensch entscheidet im Review. Erfundene Inhalte bleiben verboten.
