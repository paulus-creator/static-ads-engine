# Frameworks

Markenneutrales Handwerkswissen für Static Ads. KONZEPT liest `relevanz-gate.md`,
`hooks-und-angles.md` und `visuelle-grammatiken.md`. LEARNINGS liest
`testing-und-iteration.md`. `urgency-scarcity.md` gilt für Offer-Konzepte.
`copywriting-frameworks.md` ist Referenz für den Copywriter, nicht für die Engine (sie
schreibt keine Ad-Copy), hilft aber beim Angle.

Beispiele in diesen Dateien sind erfunden und stammen aus der Beispiel-Marke in
`example-brand/`. Ersetze sie gedanklich durch deine Kategorie.
