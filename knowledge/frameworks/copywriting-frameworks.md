# Copywriting-Frameworks (Referenz für Angle und Copywriter)

Die Engine schreibt keine Ad-Copy. Diese Frameworks helfen KONZEPT beim Angle und dem
Copywriter beim Primary Text. Eine Static hat wenig Platz: «Framework anwenden» heisst,
dass Hook, Bildzeile und Visual der Logik folgen, nicht dass jede Stufe einen Absatz
braucht. Beispiele sind erfunden (Beispiel-Marke: Nachtöl).

## 1. PAS — Problem, Agitate, Solution
Problem benennen → Schmerz konkret verschärfen → Lösung zeigen.
*Wann:* Problem-aware Cold Traffic, starker Alltagsschmerz.
*Beispiel:* «Spannt nach dem Waschen.» → «Im Winter jeden Morgen. Creme hält bis
Mittag.» → «Ein Öl, das über Nacht einzieht.»

## 2. AIDA — Attention, Interest, Desire, Action
Hook → relevanter Fakt → Ergebnis-Bild oder Social Proof → CTA.
*Wann:* universell, gut für Retargeting mit Social Proof.

## 3. Mechanism-First
Erst das einzigartige Problem-Verständnis (warum bisherige Produkte scheitern mussten),
dann die einzigartige Lösung. Das stärkste Framework für skeptische, gut informierte
Zielgruppen.
*Beispiel:* «Trockenheit ist kein Wassermangel. Es ist eine durchlässige Lipidschicht.» →
«Deshalb hat Creme nie lange gehalten: Sie ist zu 70 % Wasser.» → «Öle füllen die
Lipidschicht auf.» (Claims nur, wenn `brand/PRODUKTE.md` sie trägt.)

## 4. Objection-First
Den grössten Einwand offen aussprechen → ernst nehmen → entkräften → CTA mit
Risk-Reversal.
*Wann:* Retargeting, wenn ein Einwand nachweislich dominiert.
*Beispiel:* «‹Öl macht fettig.›» → «Verständlich, Mineralöl tut das.» → «Pflanzenöle mit
kurzer Kette ziehen in 20 Minuten ein.» → «30 Nächte testen, sonst Geld zurück.»

## 5. Before-After-Bridge
Vorher-Zustand (erlebbar, spezifisch) → Nachher-Zustand → die Brücke ist das Produkt. Oft
in Ich-Form einer echten Kundin. Nur echte, belegte Geschichten.

## Die fünf Copy-Elemente (Check für jedes Konzept)
**Promise** (Wunschzustand) · **Pain Point** (Ist-Zustand) · **Proof** (warum glauben) ·
**Constraints** (Einwände, ehrlich entkräftet) · **Mechanism** (neuer Lösungsweg,
angeteasert). Bei Statics dürfen sie auf Bildzeilen, Visual und Primary Text verteilt
sein. Spezifisch schlägt vage, immer.

## Framework-Wahl

| Situation | Erste Wahl | Alternative |
|---|---|---|
| Breiter Cold Traffic, Alltagsschmerz | PAS | AIDA |
| Skeptische Rechercheurinnen, bekanntes Scheitern | Mechanism-First | Objection-First |
| Retargeting, bekannter Einwand | Objection-First | Before-After-Bridge |
| Social-Proof-Material vorhanden | Before-After-Bridge | AIDA |
