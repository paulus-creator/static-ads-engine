# Beispiel-Marke «Nordlicht» (fiktiv)

Eine erfundene Hautpflege-Marke mit einem einzigen Produkt, damit du siehst, wie
ausgefüllte `brand/`-Dateien aussehen. Alle Namen, Preise, Claims und URLs sind
ausgedacht. Es gibt kein Produktfoto; lege für deine Marke echte Fotos ab.

Testlauf ohne Credits: `cp -r example-brand/* brand/` und in Claude Code
«Konzept-Lauf gemäss RUNBOOK, ohne Visual.»
